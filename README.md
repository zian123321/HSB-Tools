# IMEI异常拦截告警机器人
## 项目背景
二手3C仓储流程中，需要人工逐单核对IMEI验机状态，人工排查效率低、异常发现滞后，异常设备流到下游会产生库存风险和售后成本。本项目通过API自动化完成全量校验，把异常拦截在入库环节。

## 核心功能
1. 定时拉取业务系统订单/设备数据，自动去重整理
2. 对接验机系统API，批量校验IMEI状态，自动识别异常设备
3. 异常结果自动过滤分类，生成可追溯的Excel清单
4. 通过钉钉机器人Webhook实时推送异常告警，支持指定责任人
5. 配置化规则，可自定义异常状态阈值、推送时间

## 技术栈
- 运行环境：Node.js
- 能力：REST API对接、钉钉Webhook、node-cron定时任务、Excel文件处理
- 部署：支持本地/服务器后台运行，凭证自动刷新，长期免登录

## 项目价值
- 替代人工逐单核对，每天可节省1小时+重复排查时间
- 异常拦截前置，避免异常设备流入下游，降低人工出错率
- 全量校验无遗漏，异常数据可追溯，告警实时触达
