# 多业务系统 · 人效产出看板

一个纯 Python + 原生 HTML/ECharts 的轻量常驻看板：定时从多个内部业务系统拉取作业记录，按「每人每小时产出」聚合，生成单文件网页，在局域网内通过一个本地 HTTP 服务对外展示。

> 本仓库为**脱敏后的作品集示例**：接口地址、仓库编号、接口名、字段名、人员姓名均为占位或化名，不含任何真实业务数据与凭证。接入你自己的环境时，按注释逐项替换即可。

## 功能特性

- **三源聚合**：收货记录 / 验货拆包 / 真机拍照三个业务源，独立采集、独立容错。
- **人效统计**：每条记录计 1，按记录时间所在小时聚合；展示今日与近 7 天，支持按日期下钻热力图。
- **增量缓存**：首次全量翻页拉取最近 N 天，之后只拉当天新记录并按记录 ID 合并去重；缓存原子写入并留 3 天备份。
- **错误隔离**：单源凭证失效 / 网络异常不影响其他源；失败时用旧缓存兜底，看板不空白、进程不退出。
- **网络重试**：网络抖动与 5xx 指数退避重试 3 次；凭证类错误（401/403/登录超时）不重试、单独标记。
- **常驻服务**：按配置间隔定时调度（对齐自然整点/半点），连续失败自动退避探活、成功即复位；局域网 HTTP 白名单只开放看板页面；支持 Windows 登录自启。
- **状态可见**：看板顶部状态条展示更新时间、各源条数与凭证状态；配套只读诊断脚本一键定位「网络不通 / 凭证失效 / 程序报错」。
- **凭证管理**：从浏览器 Copy as cURL 一键提取并校验后写入本地凭证文件；可选浏览器自动化自动登录刷新凭证。

## 快速开始

### 1. 环境

- Python 3.9+
- 安装依赖：

```bash
pip install -r requirements.txt
```

### 2. 预览示例看板（无需联网、无需配置）

```bash
python 拉数脚本.py --demo
```

生成 `产出看板.html`，浏览器打开即可查看样式与交互（数据为随机示例）。

### 3. 接入真实环境

1. 复制 `config.example.json` 为 `config.json`，按注释填入端口、间隔、天数等参数。
2. 在 `拉数脚本.py` 的 `SYSTEMS` 配置段，把每个源的 `url / interface / params(depotId) / list_field` 替换为你环境里真实接口的值（对照浏览器 F12 → Network 里对应列表请求）。
3. 浏览器登录业务系统后，把任一接口的 Copy as cURL 存为 `curl.txt`，运行：

```bash
python 更新凭证.py curl.txt
```

校验通过后写入 `凭证.json`（该文件被 .gitignore 忽略，不会上传）。

4. 正式拉数并生成看板：

```bash
python 拉数脚本.py
```

### 4. 常驻运行（局域网看板）

```bash
python 常驻看板服务.py            # 前台运行调试
python 常驻看板服务.py --install   # 注册 Windows 登录自启（可选）
```

启动后按控制台打印的局域网地址访问，例如 `http://<本机IP>:8899/`。

## 配置说明（config.json）

| 键 | 含义 | 默认 |
| --- | --- | --- |
| `days` | 看板保留最近自然日数 | 7 |
| `page_size` | 每页请求条数 | 100 |
| `port` | 常驻服务局域网端口 | 8899 |
| `interval_seconds` | 拉数间隔（秒） | 1800 |
| `ua` | 请求头 User-Agent | 内置 Chrome UA |
| `login_username` / `login_password` / `login_url` | 仅自动登录脚本使用，不用可留空 | 空 |

## 设计要点

- **协议抽象**：三个源共用一套翻页、合并、渲染流程，差异收敛在数据源配置（接口地址、字段名、时间格式、凭证字段名）。
- **凭证与代码分离**：凭证只存本地 `凭证.json`，源码不留长期 token；`config.json` 只存非敏感参数与（可选）本地自动登录账号。
- **健壮性**：原子写缓存（先写 `.tmp` 再 `os.replace`）、日志按天轮转、调度对齐与退避、HTTP 白名单最小开放面。
- **无数据库**：状态全部由本地 JSON 缓存承载，单文件夹即可迁移。
